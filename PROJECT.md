# Configura

## Identidad

**Configura** convierte productos comunes en experiencias personales.

Es una plataforma de personalización pensada para comercios creativos: permite definir opciones, reglas y precios para que cada cliente arme un producto propio con claridad y confianza.

### Voz

- Clara y práctica.
- Cercana, sin infantilizar.
- Creativa, pero enfocada en que vender sea simple.

### Personalidad visual

- **Base:** carbón profundo — `#1C1C1B`.
- **Superficie:** marfil cálido — `#F7F4EE`.
- **Acento principal:** terracota — `#D96846`.
- **Acento secundario:** salvia — `#84997B`.
- **Tipografía:** sans geométrica para interfaz; serif suave sólo en mensajes editoriales.

### Mensaje de marca

> Haz que cada producto se sienta único.

## Estado del proyecto

Está operativo el entorno local con Next.js, TypeScript, Tailwind, Docker Compose y PostgreSQL. También están implementados el registro/login, la tienda inicial por usuario, el catálogo base y un editor inicial de opciones: selección, color, texto y checkbox. Los valores configurables pueden ajustar el precio en CLP.

El configurador público ya muestra productos publicados, sus opciones, reglas condicionales de visibilidad y el precio actualizado en vivo. El siguiente hito es el carrito y checkout simulado.
